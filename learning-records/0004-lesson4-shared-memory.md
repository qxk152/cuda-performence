## 第 4 节内容
- 主题:**shared memory**——访存瓶颈第二大武器,从"读得对"(合并/对齐)进阶到"少读"(复用)。
- 核心技能:
  1. 识别**数据复用**——先问"这份数据被读不止一次吗?"无复用(逐元素)→ shared 无益。
  2. 内存金字塔:shared 比全局快约一个数量级,且是**可控版缓存**(对比上节"别依赖缓存救场")。
  3. 三步套路:`__shared__` 声明 → 协作加载 + `__syncthreads()` → 复用。
  4. 两个 `__syncthreads()` 陷阱:漏同步读到垃圾值(时隐时现);放进 if 分支致全 block 死锁。
  5. 本质:减少全局访存 → 抬高算术强度 → roofline 右移(衔接第 1 节,埋下 GEMM tiling 钩子)。
- 4 道判断题(无复用场景 / 漏同步 / 分支内同步死锁 / 对算术强度的影响)。
